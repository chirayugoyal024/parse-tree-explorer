# Lexis — An Interactive Visualizer for LL(1), LR(0) & SLR(1) Parsing with Three-Address Code Generation

Lexis is an interactive web application designed to visualize how expressions are parsed and converted into tree structures. It helps students and developers understand compiler design concepts through real-time graphical representation.

---

##  Features

- Generate parse trees from input expressions  
- Visualize syntax structure in real time  
- Interactive and easy-to-use interface  
- Helps understand parsing logic clearly  
- Fast and responsive UI  

---

##  Overview

Parsing is a fundamental concept in compiler design where an input string is analyzed according to grammatical rules.  
This project visually represents that process by converting expressions into tree structures, making learning more intuitive and engaging.
